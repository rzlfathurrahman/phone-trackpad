# Contributing to Phone Trackpad

We love your input! We want to make contributing to Phone Trackpad as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new gestures or features

## Development Process

1. Fork the repo and create your branch from `main`.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Test your changes locally on macOS.
4. Make sure your code is clean and adheres to existing style.
5. Issue that pull request!

## Any questions?

Feel free to open an issue or reach out via GitHub discussions.
